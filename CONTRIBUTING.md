Contributing to SafeAI

Thank you for your interest in contributing to SafeAI.

Current Status

This project is currently under private development. External contributions are not accepted at this stage.

Development Guidelines

- Write clean and readable code.
- Follow the project folder structure.
- Document all major changes.
- Test new features before committing.
- Use meaningful commit messages.

Git Commit Format

Examples:

- feat: Add AI Scam Detector
- fix: Resolve login bug
- docs: Update project documentation
- refactor: Improve dashboard structure

Branch Strategy

- main – Stable version
- develop – Development branch
- feature/* – New features
- bugfix/* – Bug fixes

Code Review

Every major change should be reviewed and tested before merging into the main branch.
